# SEO Intelligence (هوش سئو)

افزونه‌ی وردپرس. داده‌ی واقعی Google Search Console را به فرصت‌های عملی سئو تبدیل می‌کند. فقط‌خواندنی.

## چه کار می‌کند؟

- اتصال به Google Search Console (OAuth یا Service Account)
- کوئری‌هایی با نمایش زیاد ولی CTR پایین را نشان می‌دهد — سریع‌ترین بردها
- صفحاتی که در جایگاه ۴ تا ۱۵ گیر کرده‌اند و یک قدم تا صفحه‌ی اول فاصله دارند
- گروه‌بندی کوئری‌های مرتبط برای تصمیم‌های خوشه‌بندی کلمه‌ی کلیدی
- روند کلیک، نمایش، میانگین جایگاه و CTR در بازه‌های قابل تنظیم

**فقط‌خواندنی.** این افزونه هرگز ترافیک، کلیک یا رفتار جستجوی جعلی نمی‌سازد؛ همه‌ی داده از ملک خودت می‌آید.

## پیش‌نیازها

وردپرس ۶.۰+ · **PHP 8.1+** · ملک Search Console متعلق به خودت · پروژه‌ی Google Cloud با Search Console API فعال

## نصب و استفاده

۱. در `/wp-content/plugins/` آپلود (پوشه‌ی **کامل** افزونه) و فعال کن.
۲. **SEO Intelligence** را از منوی کناری باز کن.
۳. حساب گوگل / Service Account را وصل و ملک را انتخاب کن.
۴. از فهرست شکاف CTR و جایگاه ۴ تا ۱۵ شروع کن؛ اول عنوان/توضیحات و محتوای همان صفحات را بهینه کن.

> **گارد یکپارچگی:** فایل اصلی به پوشه‌های `includes/` (و `admin/`) نیاز دارد. اگر نباشند، افزونه حالا به‌جای خطای مرگبار، یک اعلان مدیریتی نشان می‌دهد — از نسخه‌ی کامل دوباره نصب کن.

## حریم خصوصی و مسیر داده

داده با اعتبارنامه‌ای که خودت می‌دهی از API سرچ کنسول گوگل گرفته و در دیتابیس وردپرس ذخیره می‌شود. چیزی به سازنده ارسال نمی‌شود. هنگام حذف افزونه، جدول‌ها/گزینه‌های خودش قابل پاک‌سازی است (`uninstall.php`).

## رفع مشکل

| مشکل | راه‌حل |
|---|---|
| اعلان «plugin files are incomplete» | از ZIP کامل دوباره نصب کن |
| داده نمی‌آید | ملک تأیید نشده، ملک اشتباه انتخاب شده یا ایمیل Service Account به‌عنوان کاربر اضافه نشده |
| خطای مرگبار هنگام فعال‌سازی | نسخه‌ی PHP کمتر از ۸٫۱ است |
