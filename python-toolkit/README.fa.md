## تنظیمات و کلیدها

کلیدها از **متغیرهای محیطی** خوانده می‌شوند، نه از داخل کد. فایل `.env.example` را به `.env`
(که در git نادیده گرفته می‌شود) کپی کنید یا متغیرها را در شل export کنید.

| متغیر | استفاده | اجباری؟ |
|---|---|---|
| `REPLICATE_API_TOKEN` | `ai-apps/decor_ai_image.py` | برای همان برنامه بله |
| `NEWSAPI_KEY` | `ai-apps/crypto_analyzer.py` | اختیاری — بدون آن بخش اخبار خالی می‌ماند |
| `GOOGLE_API_KEY` | `leads/maps_leads_bot` | برای همان ابزار بله (یا `--key`) |

> `export $(grep -v '^#' .env | xargs)` استفاده کنید، یا از `.streamlit/secrets.toml` (آن هم در git نادیده گرفته می‌شود).

## تحلیلگر سئو

**سئوی درون‌صفحه‌ای** یک URL را تحلیل می‌کند یا دو URL را کنار هم مقایسه می‌کند.
محتوای فارسی و انگلیسی هر دو پشتیبانی می‌شوند (توقف‌واژه‌ها و چیدمان راست‌به‌چپ).

```bash
streamlit run seo/seo_analyzer/app.py
```

**آموزش:** آدرس محلی که Streamlit چاپ می‌کند را باز کن ← حالت *تحلیل یک URL* یا *مقایسه دو URL* را انتخاب کن ← آدرس را با `https://` بچسبان ←
دکمه‌ی تحلیل را بزن ← امتیاز را ببین و اول سراغ پیشنهادهای *اولویت بالا* برو.

### چه چیزهایی بررسی می‌شود؟

| بخش | بررسی‌ها |
|---|---|
| **متا** | وجود و طول `<title>` (۱۰ تا ۶۵ کاراکتر)، توضیحات متا (۷۰ تا ۱۶۰)، HTTPS، ویژگی `lang`، فاوآیکون، تگ کنونیکال (و تطابق با URL نهایی)، ویوپورت، تگ‌های تکراری عنوان/توضیحات |
| **ساختار** | تعداد H1 تا H6، قاعده‌ی تک‌H1، موقعیت H1، تصاویر و پوشش ALT، ALTهای تکراری، لینک‌های داخلی/خارجی/`nofollow`·`sponsored`·`ugc`، anchorهای خالی یا `#` |
| **محتوا** | تعداد کلمات (هشدار برای کمتر از ۳۰۰ و بیشتر از ۴۰۰۰)، کلمات کلیدی پرتکرار، عبارت‌های دو کلمه‌ای، کلمات تأکیدی (`strong`/`em`)، نسبت متن به HTML |
| **فنی** | وجود `robots.txt`، پیدا کردن sitemap (از جمله دستور `Sitemap:`)، Open Graph، Twitter Cards، Schema.org (انواع و خطاهای تجزیه) |
| **عناصر** | جدول، لیست، iframe، ویدئو/صوت، تشخیص اینفوگرافیک |

پیشنهادها در سه گروه **اولویت بالا**، **اولویت متوسط** و **نکات مثبت** نمایش داده می‌شوند.
خطا در یک بررسی هیچ‌وقت بقیه را متوقف نمی‌کند: هر بررسی داخل `_run_analysis_safe` اجرا می‌شود
که خطا را ثبت می‌کند و ادامه می‌دهد.

### امتیازدهی

امتیاز یعنی سهم امتیازهای کسب‌شده از **۸۶ امتیاز ممکن**، که به مقیاس ۰ تا ۱۰۰ تبدیل می‌شود.

| دسته | سقف | دسته | سقف |
|---|:-:|---|:-:|
| عنوان | ۸ | HTTPS | ۵ |
| توضیحات متا | ۸ | نسبت متن به HTML | ۳ |
| تیترها | ۱۰ | شبکه‌های اجتماعی و schema | ۸ |
| تصاویر | ۶ | کنونیکال و ویوپورت | ۶ |
| تعداد کلمات | ۵ | پاکیزگی (تکراری‌ها، anchor خالی) | ۶ |
| لینک‌ها | ۶ | تنظیمات پایه (فاوآیکون، lang) | ۳ |
| فایل‌های فنی | ۶ | عناصر محتوایی | ۶ |

این امتیاز یک **تخمین ابتکاری** است، نه پیش‌بینی رتبه. برای مقایسه‌ی دو نسخه از یک صفحه مفید است،
نه به‌عنوان حقیقت مطلق.

### استفاده به‌صورت کتابخانه

```python
from seo_analyzer import SEOAnalyzer

a = SEOAnalyzer("https://example.com")
if a.fetch():
    a.analyze()
    report, suggestions = a.get_report()
    print(report["seo_score"], len(suggestions))
```

برای افزودن یک بررسی جدید (حدود ده خط) به [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) نگاه کنید.

## ابزارهای امنیتی

> **فقط سیستم‌هایی را اسکن کنید که مالک آن هستید یا مجوز کتبی دارید.**
> در هر دو برنامه دکمه‌ی «شروع اسکن» تا وقتی تأیید مجوز را نزنید غیرفعال است.
> [docs/RESPONSIBLE_USE.md](docs/RESPONSIBLE_USE.md) را بخوانید.

### اسکنر آسیب‌پذیری هوشمند — `security/ai_web_vulnerability_scanner.py`

| ماژول | واقعاً چه می‌کند |
|---|---|
| جستجوی CVE | جستجوی آفلاین کلمه‌ی کلیدی دامنه در یک جدول کوچک داخلی |
| تستر فرم | دو payload آزمایشی (XSS و SQLi) را به هر فرمی که پیدا کند می‌فرستد و سپس یک طبقه‌بند Naive Bayes را روی **متن پاسخ** اجرا می‌کند. این طبقه‌بند فقط با پنج نمونه‌ی آموزشی ساخته شده، پس آن را **نمایش ایده** بدانید، نه ابزار تشخیص قابل‌اتکا |
| بررسی CSRF | فرم‌هایی را که هیچ input با نام شامل `csrf` ندارند علامت می‌زند |
| تشخیص فریم‌ورک | ابتکاری بر اساس هدر و محتوای صفحه (تشخیص وردپرس) |
| ریدایرکت باز و کلیک‌جکینگ | آدرس `/redirect?next=…` را امتحان می‌کند و وجود هدر `X-Frame-Options` را می‌سنجد |

گزارش‌ها در فایل JSON ذخیره می‌شوند. همه‌ی درخواست‌های HTTP محدودیت زمانی ۱۰ ثانیه دارند.

**آموزش:** `streamlit run security/ai_web_vulnerability_scanner.py` ← آدرس هدف را بنویس ← بررسی‌های دلخواه را تیک بزن ←
تیک **تأیید مجوز** را بزن (یعنی مالک هدف هستی یا مجوز کتبی داری) ← «🚀 شروع اسکن». اول روی نسخه‌ی تست سایت خودت امتحان کن.

### Deep Scanner — `security/deep_scanner.py`

| ماژول | وضعیت |
|---|---|
| تحلیل جاوااسکریپت (`eval`، `innerHTML`، الگوهای دسترسی به کوکی/سشن) | ✅ پیاده‌سازی شده |
| اسکن پورت‌های رایج (۲۱، ۲۲، ۲۳، ۲۵، ۵۳، ۸۰، ۱۱۰، ۱۴۳، ۴۴۳، ۳۳۰۶، ۳۳۸۹) | ✅ پیاده‌سازی شده |
| جستجوی CVE | ✅ جدول ساده‌ی کلمه‌ی کلیدی دامنه |
| ML فرم / CSRF / ریدایرکت-کلیک‌جکینگ | ⏳ **پیاده‌سازی نشده** — حالا به‌جای ساختن یافته‌ی ساختگی، «پیاده‌سازی نشده» گزارش می‌دهند؛ برای این موارد از اسکنر بالا استفاده کنید |
| تشخیص فریم‌ورک | ⚠️ فقط بر اساس نام دامنه |

**آموزش:** `streamlit run security/deep_scanner.py` ← همان روند بالا؛ تیک اضافه‌ی اسکن پورت هم هست.

هیچ‌کدام جای تست نفوذ حرفه‌ای یا اسکنر نگهداری‌شده‌ای مثل OWASP ZAP را نمی‌گیرند.
خروجی را نقطه‌ی شروع بررسی دستی بدانید.

- تاریخچه‌ی ۹۰ روزه‌ی قیمت از CoinGecko با نمودار Plotly
- اندیکاتورها: SMA-14، EMA-14، RSI-14 و Momentum
- یک **خط روند رگرسیون خطی ۵ روزه**. این فقط برون‌یابی آماری قیمت‌های اخیر است، *نه پیش‌بینی* و *نه توصیه‌ی مالی*.
- اخبار از NewsAPI (نیاز به `NEWSAPI_KEY`) که با `googletrans` به فارسی ترجمه می‌شود
- **پنل on-chain مقادیر ثابت نمایشی دارد**؛ در رابط کاربری هم همین‌طور برچسب خورده و در نقشه راه ثبت شده است

**آموزش:** `streamlit run ai-apps/crypto_analyzer.py` ← رمزارز را از لیست انتخاب کن ← نمودار، اندیکاتورها و خط روند را ببین. اختیاری: `export NEWSAPI_KEY=...` برای بخش اخبار. توصیه‌ی مالی نیست.

### Decor AI — بازطراحی تصویر — `ai-apps/decor_ai_image.py`

برنامه‌ی دسکتاپ Flet. عکس اتاق را به یک مدل image-to-image در Replicate می‌فرستد و تصویر اصلی را کنار
نتیجه‌ی بازطراحی‌شده نشان می‌دهد. به `REPLICATE_API_TOKEN` نیاز دارد و Replicate به ازای هر اجرا هزینه می‌گیرد.

**آموزش:** `export REPLICATE_API_TOKEN=...` ← `python ai-apps/decor_ai_image.py` ← دکمه‌ی «📂 انتخاب تصویر» و عکس اتاق ← منتظر نتیجه بمان.

### Decor AI — چت — `ai-apps/decor_ai_chat.py`

دستیار دکوراسیون داخلی. ابتدا سؤال را با فهرستی از کلمات کلیدی فارسی دکوراسیون می‌سنجد (سؤال نامرتبط را رد می‌کند)،
سپس جستجوی متنی DuckDuckGo انجام می‌دهد و سه نتیجه‌ی برتر را در رابط Flet نشان می‌دهد.

**آموزش:** `python ai-apps/decor_ai_chat.py` ← سؤال فارسی دکوراسیون را بنویس و ارسال کن.

### Decor AI — مدل محلی — `ai-apps/decor_ai_llm.py`

همان ایده‌ی چت، ولی پاسخ‌ها از یک GPT-2 فارسی که روی سیستم خودتان اجرا می‌شود (`HooshvareLab/gpt2-fa`) می‌آید.
ابتدا `transformers` و `torch` را نصب کنید (`ai-apps/requirements.txt`)؛ مدل در اولین اجرا دانلود می‌شود.
کیفیت در حد یک مدل کوچک GPT-2 است: برای دمو خوب است، برای مشاوره‌ی قابل‌اتکا نه.

**آموزش:** `pip install transformers torch` ← `python ai-apps/decor_ai_llm.py` ← صبر برای دانلود مدل در اولین اجرا ← چت.

## ابزارهای کاربردی

### بهینه‌ساز تصویر — `utilities/image_optimizer.py`

پردازش دسته‌ای تا ۲۰ تصویر: تبدیل فرمت، تغییر اندازه، فشرده‌سازی، افزایش وضوح و رنگ، واترمارک متنی یا لوگو،
دریافت تصاویر مستقیماً از آدرس یک صفحه و دانلود همه‌چیز به‌صورت ZIP.
حذف پس‌زمینه **پیاده‌سازی نشده** است (در متن قدیمی رابط تبلیغ می‌شد و حذف شد).

**آموزش:** `streamlit run utilities/image_optimizer.py` ← یا آدرس صفحه را بچسبان و «📥 دریافت تصاویر» بزن، یا تا ۲۰ تصویر آپلود کن ←
فرمت خروجی، اندازه‌ی دستی (اختیاری)، کیفیت (پیش‌فرض ۸۵)، وضوح/رنگ را تنظیم کن ← واترمارک (متن یا لوگو؛ متن به‌صورت پیش‌فرض خالی است) ←
«🚀 انجام بهینه‌سازی» ← دانلود تکی یا ZIP.

### دانلودر خودکار تصویر — `utilities/auto_image_downloader.py`

به ازای هر کلمه‌ی کلیدی N تصویر از Unsplash را در پوشه‌ای جداگانه دانلود می‌کند، با ۱ ثانیه تأخیر بین درخواست‌ها.
این ابزار HTML عمومی Unsplash را تجزیه می‌کند که ممکن است هر زمان از کار بیفتد و با شرایط استفاده‌ی آن‌ها
در تضاد باشد؛ جایگزین پیشنهادی [API رسمی Unsplash](https://unsplash.com/developers) است (در نقشه راه آمده).
همیشه مجوز و الزام ذکر منبع هر عکس را رعایت کنید.

**آموزش:** `streamlit run utilities/auto_image_downloader.py` ← هر خط یک کلمه‌ی کلیدی ← تعداد تصویر برای هر کلمه (۱ تا ۵۰) ← «🚀 شروع دانلود». مجوز عکس‌ها با صاحبانشان است.

### FileSage — `utilities/filesage/`

مرتب‌سازی پوشه‌ی شلوغ بر اساس نوع/تاریخ، پیدا کردن فایل تکراری و تصویر مشابه، گزارش HTML و Undo کامل. پیش‌فرض Dry-run است و هیچ‌چیز را حذف نمی‌کند.
`python filesage.py scan ~/Downloads -o report.html` ← `organize ... --by type` ← با `--apply` اجرا کن. راهنمای کامل: [utilities/filesage/README.fa.md](utilities/filesage/README.fa.md) ·
[نمونه گزارش](utilities/filesage/examples/sample-report.html).

## توسعه

```bash
pip install -r requirements-dev.txt

ruff check .          # لینت
pytest -q             # تست‌های آفلاین، بدون نیاز به اینترنت
```

CI (فایل `.github/workflows/ci.yml`) برای هر push و pull request لینت را اجرا می‌کند، همه‌ی برنامه‌ها را
کامپایل می‌کند و تست‌ها را روی پایتون ۳.۱۰ و ۳.۱۲ اجرا می‌کند.

قراردادها:

- پایان خط LF (با `.gitattributes`)، UTF-8، تورفتگی ۴ فاصله (`.editorconfig`)
- هیچ کلیدی داخل کد نباشد؛ از متغیر محیطی بخوانید
- هر بررسی جدید سئو یک تست در `tests/` می‌خواهد

مشارکت خوش‌آمد است — [CONTRIBUTING.md](CONTRIBUTING.md) را ببینید.

## استفاده مسئولانه

این ابزارها از طرف شما درخواست شبکه می‌فرستند و بعضی با اطلاعات تماس سروکار دارند یا فایل‌ها را تغییر می‌دهند. **مسئولیت نحوه‌ی استفاده کاملاً با خود شماست.**
فقط روی سایت‌ها، سیستم‌ها و داده‌هایی استفاده کنید که مالک آن‌ها هستید یا صراحتاً مجازید؛ `robots.txt` و محدودیت نرخ را رعایت کنید و از قوانین
کشور خود و شرایط استفاده‌ی هر سرویس شخص ثالث پیروی کنید.

نرم‌افزار **«همان‌طور که هست» و بدون ضمانت** ارائه می‌شود. سازنده (مهیار مومنی) و مشارکت‌کنندگان **هیچ مسئولیتی** در قبال خسارت، از دست رفتن داده، جریمه،
مسدودی، شکایت یا جریمه‌ی ناشی از استفاده ندارند. متن کامل، یادداشت ریسک هر ابزار و فهرست ابزارهایی که عمداً منتشر نشده‌اند:
[docs/RESPONSIBLE_USE.md](docs/RESPONSIBLE_USE.md).

## محدودیت‌های شناخته‌شده

فهرست کوتاه و صادقانه (نسخه‌ی کامل در [docs/ROADMAP.md](docs/ROADMAP.md)):

- برنامه‌های Streamlit ابزارهای تک‌کاربره‌اند، نه سرویس چندکاربره‌ی مقاوم‌شده
- Deep Scanner سه ماژول پیاده‌سازی‌نشده دارد («پیاده‌سازی نشده» گزارش می‌شوند) و تستر ML فرم در اسکنر دیگر با پنج نمونه آموزش دیده
- پنل on-chain رمزارز داده‌ی نمایشی است
- چند اسکریپت قدیمی هنوز `except:` خالی دارند؛ پاکسازی برنامه‌ریزی شده
- امتیاز سئو ابتکاری است و سرعت صفحه و داده‌ی واقعی بک‌لینک را در نظر نمی‌گیرد
- `seo_audit_bot` برای تصمیم خزش robots.txt را نمی‌خواند و تأخیر بین درخواست‌ها ندارد؛ `keyword_miner` به سرویس‌های غیررسمی وابسته است که ممکن است تغییر کنند
- ابزارهای تازه‌واردشده (`seo_audit_bot`، `keyword_miner`، `leads/*`، `filesage`) هنوز در مرحله‌ی لینت ruff نیستند؛ `b2b_lead_intel` تست‌های خودش را دارد
