# ربات استخراج کسب‌وکار از گوگل مپ (Maps Leads Bot)

**سازنده: مهیار مومنی**

[English](README.md) · بخشی از [جعبه‌ابزار پایتون مهیار](../../README.fa.md)

> **سطح ریسک:** 🟡 متوسط — API پولی؛ شرایط استفاده‌ی داده‌ی گوگل و قوانین بازاریابی/حریم خصوصی روی استفاده‌ی تو از خروجی اعمال می‌شود


این ربات با **API رسمی گوگل (Places API)** لیست کسب‌وکارهای یک صنف را در یک شهر پیدا می‌کند
(مثلاً «لباس فروشی» و «بوتیک» در تهران) و **نام، شماره تماس، آدرس، سایت، امتیاز و لینک نقشه** را در یک فایل CSV (قابل باز شدن در اکسل) ذخیره می‌کند.

---

## ۱. پیش‌نیازها

- یک کامپیوتر (ویندوز / مک / لینوکس) با اینترنت پایدار
- **پایتون نسخه ۳.۸ یا بالاتر**
- یک حساب گوگل
- یک کارت بانکی بین‌المللی برای فعال‌سازی Billing در گوگل (گوگل صرفاً برای احراز هویت می‌خواهد و طبق سهمیه رایگان ماهانه، تا سقف مشخصی هزینه‌ای کسر نمی‌شود. قوانین و قیمت‌ها را خودت در کنسول گوگل بررسی کن.)

> اگر دسترسی به Google Cloud از کشور یا شبکه‌ات محدود است، باید از روشی که قانونی و در دسترس خودت است استفاده کنی. این ربات بدون API Key کار نمی‌کند.

---

## ۲. نصب پایتون

1. به سایت https://www.python.org/downloads/ برو و نسخه جدید را دانلود کن.
2. **ویندوز:** هنگام نصب حتماً تیک **Add python.exe to PATH** را بزن و سپس Install Now.
3. بررسی نصب: ترمینال (ویندوز: `cmd` یا PowerShell) را باز کن و بزن:
   ```
   python --version
   ```
   اگر خطا داد، در ویندوز `py --version` را امتحان کن و در همه‌ی دستورات پایین به جای `python` بنویس `py`. در مک/لینوکس به جای آن `python3` بنویس.

---

## ۳. گرفتن API Key از گوگل (مرحله مهم)

1. وارد https://console.cloud.google.com شوید و با حساب گوگل وارد شوید.
2. از بالای صفحه روی لیست پروژه کلیک کن ← **New Project** ← یک اسم بده (مثلاً `maps-leads`) ← **Create**.
3. مطمئن شو پروژه جدید بالای صفحه انتخاب شده است.
4. **فعال‌سازی Billing:** منوی ☰ ← **Billing** ← یک حساب پرداخت بساز/وصل کن. (بدون این مرحله API خطا می‌دهد.)
5. **فعال‌سازی API:** منوی ☰ ← **APIs & Services** ← **Library** ← عبارت `Places API (New)` را جستجو کن ← **Enable**.
   - حتماً نسخه‌ی **(New)** را فعال کن، نه Places API قدیمی.
6. **ساخت کلید:** **APIs & Services** ← **Credentials** ← **Create Credentials** ← **API key**. کلید را کپی کن (رشته‌ای شبیه `AIzaSy...`).
7. **امن‌سازی کلید (توصیه جدی):** روی کلید کلیک کن ← بخش **API restrictions** ← **Restrict key** ← فقط **Places API (New)** را انتخاب کن ← **Save**.
8. کلید را به هیچ‌کس نده و در جایی عمومی (مثل گیت‌هاب) قرار نده.

---

## ۴. آماده‌سازی ربات

1. فایل ZIP را Extract کن تا پوشه `maps-leads-bot` ساخته شود.
2. ترمینال را باز کن و وارد پوشه شو:
   ```
   cd مسیر/پوشه/maps-leads-bot
   ```
   (ویندوز: می‌توانی در Explorer داخل پوشه، روی نوار آدرس کلیک کنی، `cmd` بنویسی و Enter بزنی.)
3. نصب کتابخانه:
   ```
   pip install -r requirements.txt
   ```
   اگر `pip` شناخته نشد: `python -m pip install -r requirements.txt`

4. **معرفی کلید به ربات** (یکی از دو روش):

   **روش الف – مستقیم در دستور (ساده‌تر):** در مرحله ۵ از `--key "کلید_تو"` استفاده کن.

   **روش ب – متغیر محیطی (امن‌تر):**
   - ویندوز CMD: `set GOOGLE_API_KEY=کلید_تو`
   - ویندوز PowerShell: `$env:GOOGLE_API_KEY="کلید_تو"`
   - مک/لینوکس: `export GOOGLE_API_KEY="کلید_تو"`

   (این متغیر فقط تا بسته شدن همان پنجره ترمینال می‌ماند.)

---

## ۵. اجرا

**تست اولیه (ارزان و سریع، ۴ منطقه):**
```
python maps_leads.py "لباس فروشی" --city tehran --grid 2 -o test.csv --key "کلید_تو"
```

**اجرای کامل برای چند صنف:**
```
python maps_leads.py "لباس فروشی" "بوتیک" --city tehran --grid 5 --with-phone-only -o tehran_clothes.csv --key "کلید_تو"
```

در حین اجرا پیشرفت نمایش داده می‌شود و در پایان پیام `Done: N businesses` می‌آید. فایل خروجی کنار ربات ساخته می‌شود و با اکسل (فارسی درست) باز می‌شود.

### توضیح گزینه‌ها

| گزینه | توضیح |
|---|---|
| `"لباس فروشی" "بوتیک"` | صنف‌ها؛ هر تعداد که بخواهی (داخل گیومه) |
| `--city` | `tehran` ، `mashhad` ، `isfahan` ، `shiraz` ، `tabriz` |
| `--grid N` | شهر به N×N بخش تقسیم می‌شود. عدد بزرگ‌تر = نتیجه بیشتر ولی هزینه و زمان بیشتر. پیشنهاد: ۴ تا ۸ |
| `--with-phone-only` | فقط کسب‌وکارهای دارای شماره تلفن |
| `--lang` | زبان نتایج (پیش‌فرض `fa`) |
| `-o` | نام فایل خروجی |
| `--key` | کلید API |

### ستون‌های خروجی
`name` نام ، `phone` شماره ، `address` آدرس ، `website` سایت ، `rating` امتیاز ، `reviews` تعداد نظر ، `maps_url` لینک گوگل مپ

## ۶. اضافه کردن شهر جدید

فایل `maps_leads.py` را با ویرایشگر باز کن، در بخش `CITIES` یک خط اضافه کن (جنوب، غرب، شمال، شرق به درجه جغرافیایی):
```python
"karaj": (35.75, 50.85, 35.90, 51.05),
```
مختصات را از گوگل مپ (کلیک راست روی نقطه) بگیر. سپس `--city karaj` استفاده کن.

## ۷. رفع مشکل (FAQ)

| خطا / مشکل | علت و راه‌حل |
|---|---|
| `API key not set` | کلید را با `--key` بده یا متغیر محیطی را در **همان** پنجره ترمینال تنظیم کن |
| `API error 403` / `PERMISSION_DENIED` | Places API (New) فعال نیست، یا Billing وصل نیست، یا محدودیت کلید اشتباه است |
| `API error 400` | معمولاً ورودی/مختصات اشتباه یا نام صنف خالی |
| `API error 429` | سهمیه تمام شده؛ کمی صبر کن یا `--grid` را کم کن |
| `ModuleNotFoundError: requests` | مرحله `pip install -r requirements.txt` را انجام بده |
| `python is not recognized` | پایتون با PATH نصب نشده؛ دوباره نصب کن یا از `py` استفاده کن |
| تعداد نتایج کم است | `--grid` را بیشتر کن یا صنف‌های هم‌معنی اضافه کن (مثلاً «مزون» ، «پوشاک») |
| شماره برخی کسب‌وکارها خالی است | آن کسب‌وکار شماره‌ای در گوگل ثبت نکرده است |
| فارسی در اکسل خراب است | فایل را با Data ← From Text/CSV و Encoding = UTF-8 باز کن |

## ۸. نکات مهم هزینه و قانون

- فیلد شماره تلفن جزو دسته‌ی گران‌تر Places API است. قبل از اجرای بزرگ، **Budget Alert** بگذار: Billing ← Budgets & alerts.
- هر `--grid N` تقریباً به تعداد `N×N×تعداد صنف×(تا ۳ صفحه)` درخواست می‌زند.
- از اطلاعات فقط مطابق قوانین کشور و شرایط استفاده‌ی گوگل استفاده کن. ارسال پیامک/تماس انبوه بدون رضایت ممنوع و باعث بلاک شدن می‌شود.
- شرایط استفاده از داده‌های گوگل ممکن است محدودیت‌هایی برای ذخیره‌سازی بلندمدت یا بازفروش داشته باشد؛ آن را بررسی کن.
