# B2B Lead Intelligence Engine (موتور هوشمند سرنخ B2B)

**سازنده: مهیار مومنی (Mahyar Momeni)** • نسخه ۱.۰.۰

[English](README.md) · بخشی از [جعبه‌ابزار پایتون مهیار](../../README.fa.md)

> **سطح ریسک:** 🟡 متوسط — استخراج اطلاعات تماس تابع قوانین حریم خصوصی/ضد اسپم و شرایط سایت‌هاست


لیستی از دامنه‌ی شرکت‌ها را می‌گیرد و برای هر کدام **اطلاعات تماس عمومی، شبکه‌های اجتماعی، تکنولوژی‌های سایت** را استخراج می‌کند، سرنخ را **امتیازدهی و گرید‌بندی (A تا D)** می‌کند و حتی **زاویه فروش پیشنهادی** می‌دهد (مثلاً «سایت آنالیتیکس ندارد ← فرصت فروش GA4»). خروجی: دیتابیس SQLite، داشبورد HTML تعاملی، CSV و JSON.
**بدون API Key • رایگان • قابل ازسرگیری (Resume) • محترم به robots.txt**

---

## ۱. قابلیت‌ها
- کراول **ناهمزمان (asyncio)** با کنترل همزمانی، تأخیر مؤدبانه برای هر هاست، Retry با Backoff نمایی، پشتیبانی از `Retry-After`
- رعایت **robots.txt** (به‌صورت پیش‌فرض روشن)
- استخراج **ایمیل** از mailto، متن، فرمت‌های مبهم (`name [at] site [dot] com`) و **رمزگشایی ایمیل‌های Cloudflare**؛ تشخیص ایمیل عمومی (info/sales) از شخصی و ایمیل هم‌دامنه
- استخراج **تلفن** از لینک tel، متن، واتساپ؛ **نرمال‌سازی** به فرمت بین‌المللی، پشتیبانی از **ارقام فارسی/عربی** و فرمت موبایل و ثابت ایران
- استخراج **شبکه‌های اجتماعی** (لینکدین، اینستاگرام، تلگرام، توییتر/X، فیسبوک، یوتیوب، واتساپ، گیت‌هاب، آپارات) با حذف لینک‌های اشتراک‌گذاری
- خواندن **JSON-LD** (نام شرکت، آدرس، تعداد کارمند، sameAs)
- تشخیص **۳۰+ تکنولوژی** (وردپرس، شاپیفای، GA4، GTM، پیکسل متا، HubSpot، Cloudflare، React و ...)
- پیدا کردن خودکار صفحات «تماس / درباره ما» (فارسی و انگلیسی) و کراول آن‌ها
- **امتیازدهی شفاف و قابل تنظیم** با فایل JSON وزن‌ها + دلایل امتیاز
- ذخیره‌ی هر نتیجه بلافاصله در SQLite ← با Ctrl+C چیزی از دست نمی‌رود، اجرای مجدد ادامه می‌دهد
- داشبورد HTML (جستجو، فیلتر گرید، مرتب‌سازی، جزئیات هر شرکت، خروجی CSV)
- **۲۳ تست خودکار** شامل تست سرتاسری روی سرور محلی

## ۲. نصب (مرحله به مرحله)
1. پایتون ۳.۹ یا بالاتر: https://www.python.org/downloads/ (ویندوز: تیک **Add python.exe to PATH**)
2. بررسی: `python --version` (ویندوز اگر خطا داد `py`؛ مک/لینوکس `python3` — در همه دستورات جایگزین کن)
3. ZIP را Extract کن و ترمینال را داخل پوشه `b2b-lead-intel` باز کن
   (ویندوز: داخل پوشه روی نوار آدرس کلیک ← `cmd` ← Enter)
4. (توصیه‌شده) محیط مجازی:
   ```
   python -m venv venv
   venv\Scripts\activate          (ویندوز)
   source venv/bin/activate       (مک/لینوکس)
   ```
5. نصب کتابخانه‌ها:
   ```
   pip install -r requirements.txt
   ```
6. تست سلامت نصب (باید `OK` ببینی):
   ```
   python -m unittest discover -s tests -t .
   ```

## ۳. استفاده

### مرحله ۱: فایل دامنه‌ها
یک فایل متنی بساز (مثلاً `domains.txt`)؛ هر خط یک دامنه یا URL. فایل CSV هم قبول است. تکراری‌ها و خطوط نامعتبر خودکار حذف می‌شوند، خطوط با `#` نادیده گرفته می‌شوند.
```
acme.com
https://www.beta.io/about
gamma.ir
```
### مرحله ۲: اجرا
```
python -m b2b_intel run domains.txt
```
یا مستقیم:
```
python -m b2b_intel run --domains acme.com beta.io
```
### مرحله ۳: داشبورد و خروجی
```
python -m b2b_intel report -o report.html
python -m b2b_intel export --format csv --min-grade B -o hot-leads.csv
python -m b2b_intel stats
```
فایل `report.html` را با دابل‌کلیک در مرورگر باز کن. روی هر ردیف کلیک کنی جزئیات و زاویه فروش باز می‌شود.

### گزینه‌های دستور `run`
| گزینه | پیش‌فرض | توضیح |
|---|---|---|
| `--db` | leads.db | مسیر دیتابیس SQLite |
| `--concurrency` | 10 | تعداد دامنه‌ی همزمان |
| `--delay` | 1.0 | فاصله (ثانیه) بین درخواست‌ها به یک هاست |
| `--timeout` | 15 | زمان‌بندی هر درخواست |
| `--max-pages` | 4 | صفحه اصلی + صفحات تماس/درباره |
| `--force` | خاموش | دامنه‌های قبلاً بررسی‌شده را دوباره کراول کن |
| `--weights` | — | فایل JSON وزن‌های امتیازدهی (نمونه: `weights.example.json`) |
| `--ignore-robots` | خاموش | **پیشنهاد نمی‌شود**؛ رعایت robots.txt را خاموش می‌کند |

### دستور `export`
`--format csv|json` ، `--min-grade A|B|C|D` ، `-o فایل`

## ۴. امتیازدهی
هر قاعده وزنی دارد؛ امتیاز نهایی نسبت وزن‌های برآورده‌شده به کل (۰ تا ۱۰۰) است:
ایمیل هم‌دامنه (۲۲) • ایمیل شخصی (۱۰) • هر ایمیل (۶) • تلفن (۱۴) • موبایل (۶) • لینکدین (۱۰) • ۲+ شبکه اجتماعی (۶) • آدرس (۴) • توضیحات (۳) • فروشگاه آنلاین (۸) • ابزار بازاریابی/CRM (۸) • اندازه شرکت (۳)

گرید: **A ≥ ۷۰** • **B ≥ ۵۰** • **C ≥ ۳۰** • **D** کمتر. با فایل `weights.example.json` می‌توانی وزن‌ها را مطابق مشتری ایده‌آل خودت تغییر بدهی. دلایل هر امتیاز در داشبورد نمایش داده می‌شود.

## ۵. معماری (برای برنامه‌نویس‌ها)
```
b2b_intel/
├── cli.py         رابط خط فرمان (run / report / export / stats)
├── pipeline.py    ورودی → کراول async → merge → امتیاز → ذخیره (Queue + Worker Pool)
├── fetcher.py     لایه HTTP: semaphore، throttle به‌ازای هاست، robots cache، retry، سقف حجم
├── extractors.py  توابع خالص (بدون I/O) برای ایمیل/تلفن/شبکه/JSON-LD/لینک تماس
├── techdetect.py  امضاهای Regex برای تشخیص تکنولوژی (HTML + هدرها)
├── scoring.py     قواعد امتیازدهی + زاویه‌های فروش
├── storage.py     SQLite (WAL، upsert، ایندکس)
├── report.py      داشبورد HTML خودکفا
├── models.py      dataclass ها (Lead / PageData / FetchResult)
└── config.py      Config تغییرناپذیر
tests/             تست واحد + تست E2E با سرور aiohttp محلی
```
نکات طراحی: توابع استخراج خالص و جدا از شبکه‌اند (تست‌پذیری بالا)؛ خطای یک سایت هرگز کل اجرا را نمی‌شکند؛ ذخیره‌سازی تراکنشی و idempotent است؛ سقف دانلود از مصرف حافظه جلوگیری می‌کند.

## ۶. رفع مشکل
| مشکل | راه‌حل |
|---|---|
| `ModuleNotFoundError` | `pip install -r requirements.txt` (داخل venv فعال) |
| `python is not recognized` | پایتون با PATH نصب نشده؛ دوباره نصب کن یا `py` بزن |
| وضعیت `unreachable` زیاد | اینترنت/VPN را بررسی کن؛ `--timeout 30` و `--concurrency 5` |
| وضعیت `blocked` | سایت در robots.txt ربات‌ها را ممنوع کرده؛ احترام بگذار |
| ایمیل/تلفنی پیدا نشد | ممکن است سایت با JavaScript ساخته شده یا اطلاعات را عمداً پنهان کرده باشد |
| می‌خواهم از اول شروع کنم | فایل `leads.db` را پاک کن یا `--force` بزن |
| فارسی در اکسل خراب است | CSV را با Data ← From Text/CSV و UTF-8 باز کن |

## ۷. محدودیت‌ها
- محتوای ساخته‌شده فقط با جاوااسکریپت (SPA) دیده نمی‌شود (HTML خام خوانده می‌شود).
- ربات کشف شرکت نمی‌کند؛ لیست دامنه‌ها را خودت می‌دهی.
- ایمیل‌ها «آدرس‌های عمومی منتشرشده» هستند و صحت‌سنجی SMTP انجام نمی‌شود.

## ۸. اخلاق و قانون (مهم)
- فقط **اطلاعات تماس کسب‌وکارها که خودشان عمومی منتشر کرده‌اند** را جمع کن، نه اطلاعات خصوصی افراد.
- پیش‌فرض‌ها (robots.txt، تأخیر مؤدبانه) را خاموش نکن و شرایط استفاده‌ی سایت‌ها را رعایت کن.
- ارسال ایمیل/پیامک تبلیغاتی انبوه بدون رضایت، طبق قوانین (GDPR، CAN-SPAM و قوانین محلی) ممنوع است؛ همیشه گزینه‌ی لغو عضویت بگذار و پیام شخصی‌سازی‌شده بفرست.

## ۹. نکات تکمیلی
- دستور `report` گزینه‌ی `--min-score N` هم دارد و `export` گزینه‌ی `--min-grade`.
- گزینه‌ی `--ignore-robots` رعایت robots.txt را خاموش می‌کند. استفاده‌ی آن و پیامدهایش **کاملاً بر عهده‌ی خودت** است و توصیه نمی‌شود.
- فایل `leads.db` و خروجی‌ها شامل اطلاعات تماس‌اند؛ آن‌ها را امن نگهدار، در گیت‌هاب نگذار (در `.gitignore` هستند) و داده‌ی غیرضروری را حذف کن.
