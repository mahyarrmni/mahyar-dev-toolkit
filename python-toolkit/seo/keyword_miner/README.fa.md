# ربات کلمات کلیدی (Keyword Miner)

**سازنده: مهیار مومنی**

[English](README.md) · بخشی از [جعبه‌ابزار پایتون مهیار](../../README.fa.md)

> **سطح ریسک:** 🟡 کم تا متوسط — از سرویس‌های پیشنهاد خودکار غیررسمی استفاده می‌کند


از یک کلمه، **صدها ایده جستجوی واقعی** می‌سازد: از پیشنهاد خودکار (Autocomplete) گوگل، یوتیوب و بینگ استفاده می‌کند، قصد جستجوی هر کلمه (خرید / مقایسه / اطلاعاتی) را تشخیص می‌دهد، کلمات را دسته‌بندی می‌کند و یک **گزارش HTML تعاملی** (جستجو، فیلتر، کپی) و فایل CSV می‌سازد.
مناسب: ایده محتوا برای بلاگ و یوتیوب، پیدا کردن کلمات خرید برای سئو و تبلیغات، تحقیق بازار.
**بدون API Key و رایگان.**

---

## ۱. پیش‌نیازها
- پایتون ۳.۸ یا بالاتر
- اینترنت با دسترسی به گوگل (در صورت فیلتر بودن، با روش قانونی و در دسترس خودت متصل شو)

## ۲. نصب پایتون
1. از https://www.python.org/downloads/ دانلود کن.
2. ویندوز: هنگام نصب تیک **Add python.exe to PATH** را بزن.
3. بررسی: `python --version`
   (ویندوز اگر خطا داد: `py`؛ مک/لینوکس: `python3` — در همه دستورات جایگزین کن.)

## ۳. آماده‌سازی
1. فایل ZIP را Extract کن.
2. ترمینال را داخل پوشه `keyword-miner` باز کن
   (ویندوز: داخل پوشه روی نوار آدرس کلیک کن، `cmd` بنویس، Enter.)
3. نصب:
   ```
   pip install -r requirements.txt
   ```
   (اگر نشد: `python -m pip install -r requirements.txt`)

## ۴. اجرا
فارسی:
```
python keyword_miner.py "خرید لپ تاپ" --lang fa -o laptop.html
```
انگلیسی:
```
python keyword_miner.py "dog training" --lang en -o dog.html
```
حالت عمیق (نتایج بسیار بیشتر، کندتر):
```
python keyword_miner.py "طراحی سایت" --deep -o site.html
```
چند کلمه همزمان:
```
python keyword_miner.py "سئو" "طراحی سایت" "تبلیغات گوگل" -o marketing.html
```
در پایان فایل `.html` را در مرورگر باز کن. فایل `.csv` هم برای اکسل ساخته می‌شود.

### گزینه‌ها
| گزینه | توضیح |
|---|---|
| `seeds` | یک یا چند کلمه پایه (داخل گیومه) |
| `--lang` | زبان: `fa` ، `en` ، `ar` ، `tr` ... (پیش‌فرض fa) |
| `--sources` | منابع، مثلاً `google,youtube` (پیش‌فرض هر سه) |
| `--deep` | علاوه بر پیشوند/پسوند، با تک‌تک حروف الفبا هم گسترش می‌دهد |
| `--delay` | فاصله بین درخواست‌ها به ثانیه (پیش‌فرض ۰.۱۵). اگر خطا/بلاک دیدی بیشترش کن |
| `-o` | نام فایل خروجی |

## ۵. گزارش HTML
- **کارت‌های آماری:** کل کلمات، تعداد با قصد خرید، اطلاعاتی و نمایش‌داده‌شده
- **فیلتر قصد جستجو:** خرید (سبز) / مقایسه (زرد) / اطلاعاتی (بنفش)
- **فیلتر دسته‌ها:** کلمات بر اساس موضوع مشترک گروه می‌شوند
- **جستجوی زنده** و **مرتب‌سازی** با کلیک روی سرستون
- دکمه ⧉ کپی یک کلمه و «کپی همه» برای کپی نتایج فیلترشده

## ۶. چطور از نتایج استفاده کنم؟
- کلمات **اطلاعاتی** ← ایده مقاله بلاگ و ویدیو یوتیوب
- کلمات **خرید** ← صفحات محصول/خدمات و کمپین تبلیغاتی
- کلمات **مقایسه** ← مقاله «بهترین ...» و بررسی محصول
- دسته‌های پرتکرار ← ساختار منوی سایت و خوشه‌های محتوا

## ۷. رفع مشکل
| مشکل | راه‌حل |
|---|---|
| `no results` | اینترنت یا دسترسی به گوگل را بررسی کن؛ `--delay 0.5` را امتحان کن |
| تعداد نتایج کم است | `--deep` را بزن یا کلمه پایه را کوتاه‌تر/عمومی‌تر کن |
| `ModuleNotFoundError` | `pip install -r requirements.txt` |
| `python is not recognized` | پایتون با PATH نصب نشده؛ دوباره نصب کن یا از `py` استفاده کن |
| فارسی در اکسل خراب است | CSV را با Data ← From Text/CSV و UTF-8 باز کن |
| کلمات عجیب یا نامرتبط | پیشنهادها را خود گوگل می‌دهد؛ نتایج را دستی پالایش کن |

## ۸. نکات
- ربات از سرویس پیشنهاد خودکار عمومی (بدون کلید) استفاده می‌کند که رسمی و تضمین‌شده نیست و ممکن است تغییر کند. با تعداد درخواست زیاد ممکن است موقتاً محدود شوی؛ `--deep` را زیاد اجرا نکن.
- این ابزار حجم جستجو (Search Volume) نمی‌دهد؛ فقط ایده‌ها و قصد جستجو را می‌دهد.

## ۹. توضیح تکمیلی
- این ابزار **حجم جستجو، سختی و CPC نمی‌دهد**؛ فقط ایده و قصد جستجو. کلمات امیدبخش را با ابزار رسمی (Search Console، Keyword Planner) راستی‌آزمایی کن.
- نتایج و فایل‌های خروجی تحقیق کلمات کلیدی تو محرمانه‌ی کسب‌وکار توست؛ در این ریپو فایل‌های خروجی به‌صورت پیش‌فرض در `.gitignore` هستند و نباید آن‌ها را عمومی کنی.
