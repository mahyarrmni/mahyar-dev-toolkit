# ربات آنالیز سئو (SEO Audit Bot)

**سازنده: مهیار مومنی**

[English](README.md) · بخشی از [جعبه‌ابزار پایتون مهیار](../../README.fa.md)

> **سطح ریسک:** 🟢 کم — فقط برای سایت‌های خودت یا سایت‌هایی که اجازه‌ی بررسی‌شان را داری


یک سایت را خودکار می‌خزد (Crawl) و یک **گزارش HTML زیبا** با امتیاز سئو از ۱۰۰ می‌سازد:
ضعیف‌ترین صفحات، لینک‌های شکسته، مشکلات Title/Description/H1، تصاویر بدون alt، صفحات کند، محتوای کم، noindex، موبایل‌فرندلی، Open Graph، وجود robots.txt و sitemap.xml و HTTPS.
**نیاز به API Key ندارد و کاملاً رایگان است.** (مناسب برای فریلنسرها: گزارش را به مشتری بده!)

---

## ۱. پیش‌نیازها
- پایتون ۳.۸ یا بالاتر
- اینترنت

## ۲. نصب پایتون
1. از https://www.python.org/downloads/ دانلود کن.
2. ویندوز: هنگام نصب تیک **Add python.exe to PATH** را بزن.
3. بررسی: در ترمینال بزن `python --version`
   (ویندوز اگر خطا داد: `py`؛ مک/لینوکس: `python3` — در همه دستورات پایین جایگزین کن.)

## ۳. آماده‌سازی
1. فایل ZIP را Extract کن.
2. ترمینال را داخل پوشه `seo-audit-bot` باز کن
   (ویندوز: داخل پوشه روی نوار آدرس کلیک کن، `cmd` بنویس، Enter.)
3. نصب کتابخانه‌ها:
   ```
   pip install -r requirements.txt
   ```
   (اگر نشد: `python -m pip install -r requirements.txt`)

## ۴. اجرا
تست سریع (۲۰ صفحه):
```
python seo_audit.py https://example.com --max 20
```
بررسی کامل‌تر:
```
python seo_audit.py https://yoursite.com --max 200 -o yoursite-report.html
```
پس از پایان، فایل `.html` را با دابل‌کلیک در مرورگر باز کن. یک فایل `.csv` هم کنارش ساخته می‌شود (برای اکسل).

### گزینه‌ها
| گزینه | توضیح |
|---|---|
| `url` | آدرس سایت (با یا بدون https) |
| `--max N` | حداکثر تعداد صفحه برای بررسی (پیش‌فرض ۵۰) |
| `--workers N` | تعداد درخواست همزمان (پیش‌فرض ۶). برای سایت‌های ضعیف عدد را کم کن |
| `--no-external` | لینک‌های خارجی بررسی نشوند (سریع‌تر) |
| `-o فایل.html` | نام فایل گزارش |

## ۵. معیارهای امتیازدهی
هر صفحه از ۱۰۰ شروع می‌شود و با هر مشکل امتیاز کم می‌شود (مثلاً نبود Title: ‎−۲۰، نبود H1 یا Description: ‎−۱۲، noindex: ‎−۱۵، لینک شکسته: ‎−۱۰). صفحه‌ای که خطای ۴۰۴ یا ۵۰۰ بدهد امتیاز ۰ می‌گیرد. امتیاز کل میانگین صفحات است.
- 🟢 ۸۰ و بالاتر: خوب
- 🟠 ۶۰ تا ۷۹: نیاز به بهبود
- 🔴 زیر ۶۰: ضعیف

## ۶. رفع مشکل
| مشکل | راه‌حل |
|---|---|
| `could not reach the site` | آدرس را بررسی کن؛ سایت ممکن است ربات‌ها را بلاک کند یا نیاز به VPN داشته باشد |
| `ModuleNotFoundError` | `pip install -r requirements.txt` را اجرا کن |
| `python is not recognized` | پایتون با PATH نصب نشده؛ دوباره نصب کن یا `py` بزن |
| اجرا کند است | `--max` و `--workers` را تنظیم کن یا `--no-external` بزن |
| سایت با جاوااسکریپت (React/SPA) ساخته شده | این ربات HTML خام را می‌خواند؛ محتوای ساخته‌شده با JS دیده نمی‌شود |
| بعضی لینک‌ها شکسته نشان داده می‌شوند ولی در مرورگر باز می‌شوند | بعضی سایت‌ها (شبکه‌های اجتماعی) ربات را رد می‌کنند؛ نتیجه را دستی بررسی کن |

## ۷. نکات
- فقط سایت‌های خودت یا سایت‌هایی که اجازه داری را بررسی کن و `--workers` را بالا نبر تا فشار زیادی به سرور نیاید.
- ربات فقط صفحات همان دامنه را می‌خزد.

## ۸. محدودیت‌های دقیق ابزار
- فقط صفحات **همان دامنه** را می‌خزد؛ اما برای بررسی لینک‌های خارجی به سایت‌های دیگر هم درخواست (HEAD/GET) می‌فرستد (با `--no-external` خاموش می‌شود).
- **robots.txt را برای تصمیم‌گیری درباره‌ی خزیدن نمی‌خواند** (فقط وجودش را گزارش می‌کند) و **تأخیر بین درخواست‌ها ندارد**؛ پس فقط روی سایت‌های خودت و با `--workers` منطقی اجرا کن.
- HTML خام را می‌خواند؛ محتوای ساخته‌شده با جاوااسکریپت دیده نمی‌شود.
- نمونه‌ی واقعی گزارش: [`examples/sample-report.html`](examples/sample-report.html) • امتیاز یک شاخص تقریبی است، نه پیش‌بینی رتبه.
