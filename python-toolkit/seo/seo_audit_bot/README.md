# SEO Audit Bot

[فارسی](README.fa.md) · part of [Mahyar's Python Toolkit](../../README.md)

Crawls **one website** and produces a self-contained **HTML report** (plus a CSV) with an SEO score out of 100:
weakest pages first, broken links, missing titles/descriptions/H1, images without ALT, slow or thin pages, `noindex`,
mobile viewport, Open Graph, and site-level checks for `robots.txt`, `sitemap.xml` and HTTPS.
No API key, no account, free. A real example is in [`examples/sample-report.html`](examples/sample-report.html).

| | |
|---|---|
| **Risk level** | 🟢 Low — only for sites you own or are allowed to audit |
| **Needs** | Python 3.8+, `requests`, `beautifulsoup4` |
| **Output** | `seo-report.html` + `seo-report.csv` |

## Install

```bash
cd seo/seo_audit_bot
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
(Windows: if `python` is not found use `py`; macOS/Linux may need `python3`.)

## Usage

```bash
# quick test: first 20 pages
python seo_audit.py https://example.com --max 20

# fuller audit with a custom report name
python seo_audit.py https://yoursite.com --max 200 -o yoursite-report.html

# gentler / faster variants
python seo_audit.py https://yoursite.com --workers 2          # slow servers
python seo_audit.py https://yoursite.com --no-external        # skip external link checks
```
Open the generated `.html` in a browser. The CSV (same name, `.csv`) opens in Excel
(import as UTF-8 if Persian text looks broken).

| Option | Default | Meaning |
|---|:-:|---|
| `url` | — | Site to audit (`https://` is added if missing) |
| `--max N` | 50 | Maximum pages to crawl |
| `--workers N` | 6 | Parallel requests. Lower it for weak servers |
| `--no-external` | off | Do not check links that point to other domains |
| `-o FILE` | `seo-report.html` | Report file name |

## How the score works

Every page starts at 100 and loses points per issue; a page that is not HTTP 200 scores 0. The site score is the average.
🟢 80+ good · 🟠 60–79 needs work · 🔴 below 60 weak.

| Issue | Penalty | Issue | Penalty |
|---|:-:|---|:-:|
| No `<title>` | −20 | `noindex` | −15 |
| No H1 | −12 | No meta description | −12 |
| Broken link on page | −10 | Page served over HTTP | −10 |
| Title length outside 30–60 | −8 | Images without ALT | −8 |
| Fewer than 300 words | −8 | Response slower than 1.5 s | −8 |
| No viewport tag | −8 | Description outside 70–160 | −5 |
| More than one H1 | −5 | No canonical | −4 |
| No Open Graph | −3 | | |

## What it does and does not do

- Crawls only pages on the **same host** as the start URL; skips images, PDFs, CSS/JS and similar files.
- Checks external links with `HEAD`/`GET` requests (so it does contact other sites; use `--no-external` to avoid it).
- Reads the **raw HTML**. Content generated by JavaScript (React/SPA) is not seen.
- Does **not** read `robots.txt` to decide what to crawl (it only reports whether the file exists) and has **no per-host delay**.
  That is why it must only be pointed at sites you own or administer, with a sensible `--workers` value.
- The score is a heuristic for finding regressions, not a prediction of rankings.

## Troubleshooting

| Problem | Fix |
|---|---|
| `could not reach the site` | Check the URL; the site may block bots or require a VPN |
| `ModuleNotFoundError` | `pip install -r requirements.txt` inside the active venv |
| Slow run | Lower `--max`, adjust `--workers`, add `--no-external` |
| Social links reported broken but open in a browser | Those sites reject bots; verify manually |
