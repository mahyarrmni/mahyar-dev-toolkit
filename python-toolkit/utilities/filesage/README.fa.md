# FileSage — مرتب‌کننده هوشمند فایل + یابنده تکراری و تصاویر مشابه

**سازنده: مهیار مومنی (Mahyar Momeni)**

[English](README.md) · بخشی از [جعبه‌ابزار پایتون مهیار](../../README.fa.md)

> **سطح ریسک:** 🟢 کم — فایل‌ها را فقط جابجا می‌کند و هرگز حذف نمی‌کند؛ باز هم از داده‌ی مهم بکاپ بگیر


پوشه‌ی شلوغ دانلودها، عکس‌ها یا هارد را با چند دستور مرتب می‌کند:
- 🗂 **مرتب‌سازی** خودکار بر اساس نوع (تصاویر، ویدیو، اسناد...) و/یا تاریخ (سال/ماه)
- 🔁 پیدا کردن **فایل‌های تکراری دقیق** (مقایسه محتوا با SHA-256، نه فقط اسم)
- 🖼 پیدا کردن **تصاویر مشابه** (کوچک‌شده، فشرده‌شده یا ذخیره‌شده با فرمت دیگر) با Perceptual Hash
- 📊 **گزارش HTML زیبا**: نمودار مصرف فضا، گروه‌های تکراری، پیش‌نمایش تصاویر مشابه، سنگین‌ترین فایل‌ها
- ↩️ **Undo کامل**: هر جابجایی ثبت می‌شود و با یک دستور برمی‌گردد

**ایمنی:** به‌صورت پیش‌فرض فقط **پیش‌نمایش** (Dry-run) نشان می‌دهد؛ برای اجرای واقعی باید `--apply` بزنی. **هیچ فایلی حذف نمی‌شود**، فقط جابجا می‌شود. بدون اینترنت و بدون API کار می‌کند.

## ۱. نصب
1. پایتون ۳.۱۰ یا بالاتر: https://www.python.org/downloads/ (ویندوز: تیک **Add python.exe to PATH**)
2. بررسی: `python --version` (ویندوز اگر خطا داد `py`؛ مک/لینوکس `python3`)
3. ZIP را Extract کن و ترمینال را داخل پوشه `file-sage` باز کن
   (ویندوز: داخل پوشه روی نوار آدرس کلیک ← `cmd` ← Enter)
4. نصب کتابخانه (فقط برای تصاویر مشابه لازم است):
   ```
   pip install -r requirements.txt
   ```

## ۲. استفاده (مرحله به مرحله)
در مثال‌ها مسیر پوشه‌ات را بگذار (ویندوز مثلاً `"C:\Users\Ali\Downloads"`).

### الف) اول گزارش بگیر (کاملاً بی‌خطر، چیزی تغییر نمی‌کند)
```
python filesage.py scan "C:\Users\Ali\Downloads" -o report.html
```
فایل `report.html` را در مرورگر باز کن.

### ب) مرتب‌سازی
پیش‌نمایش:
```
python filesage.py organize "C:\Users\Ali\Downloads" --by type
```
اگر نتیجه خوب بود، اجرای واقعی:
```
python filesage.py organize "C:\Users\Ali\Downloads" --by type --apply
```
حالت‌های `--by`: `type` (پوشه‌ی نوع) • `date` (سال/ماه) • `both` (نوع/سال/ماه).
به‌صورت پیش‌فرض فقط فایل‌های سطح اول پوشه مرتب می‌شوند؛ برای شامل شدن زیرپوشه‌ها `--recursive` بزن.

### ج) جابجایی تکراری‌ها
```
python filesage.py dupes "C:\Users\Ali\Pictures"            (پیش‌نمایش)
python filesage.py dupes "C:\Users\Ali\Pictures" --apply    (اجرا)
```
از هر گروه تکراری، **قدیمی‌ترین نسخه** سر جایش می‌ماند و بقیه به پوشه `_duplicates` می‌روند. وقتی مطمئن شدی خودت آن پوشه را پاک کن.

### د) برگرداندن (Undo)
```
python filesage.py undo "C:\Users\Ali\Downloads"
```
آخرین عملیات را برمی‌گرداند و پوشه‌های خالی‌شده را پاک می‌کند. می‌توانی چند بار پشت‌سرهم اجرا کنی تا عملیات‌های قبلی هم برگردند.

## ۳. دسته‌بندی نوع فایل‌ها
Images • Videos • Audio • Documents • Archives • Code • Apps • Fonts • Other
(لیست پسوندها در بالای فایل `filesage.py` در `CATS` قابل ویرایش است.)

## ۴. نحوه کار (خلاصه فنی)
- **تکراری دقیق:** گروه‌بندی بر اساس حجم ← هش ۶۴ کیلوبایت اول ← SHA-256 کامل؛ فقط فایل‌هایی که احتمال تطابق دارند کامل خوانده می‌شوند، پس روی پوشه‌های بزرگ سریع است. هش‌ها موازی (Thread) محاسبه می‌شوند.
- **تصاویر مشابه:** dHash ۶۴بیتی + فاصله همینگ ≤ ۵ + خوشه‌بندی Union-Find (حداکثر ۴۰۰۰ تصویر در هر اجرا).
- **Undo:** ژورنال JSON در همان پوشه (`.filesage-journal-*.json`)؛ حتی اگر وسط کار قطع شود، آنچه جابجا شده ثبت و برگشت‌پذیر است. در تداخل نام، فایل‌ها بازنویسی نمی‌شوند (`name (1).ext`).

## ۵. رفع مشکل
| مشکل | راه‌حل |
|---|---|
| `python is not recognized` | پایتون با PATH نصب نشده؛ دوباره نصب کن یا از `py` استفاده کن |
| بخش تصاویر مشابه خالی/پیام Pillow | `pip install -r requirements.txt` |
| `folder not found` | مسیر را داخل گیومه و درست بنویس |
| خطای Permission | فایل در حال استفاده است یا دسترسی نداری؛ برنامه‌های باز را ببند |
| تصویر مشابه پیدا نمی‌شود | عکس‌های HEIC/RAW/SVG پشتیبانی نمی‌شوند (فقط jpg/png/webp/bmp/gif/tiff) |

## ۶. توصیه‌ها
- روی پوشه‌های سیستمی (Windows، Program Files) اجرا نکن؛ فقط پوشه‌های شخصی.
- قبل از اولین `--apply` روی داده‌ی مهم، یک نسخه پشتیبان بگیر.
- «تصاویر مشابه» فقط نمایش داده می‌شود و خودکار جابجا نمی‌شود؛ تصمیم با خودت است.

## ۷. نکات
- پوشه‌ی `_duplicates` را بعد از بررسی دستی خودت پاک کن؛ برنامه چیزی حذف نمی‌کند. نمونه‌ی گزارش: [`examples/sample-report.html`](examples/sample-report.html).
