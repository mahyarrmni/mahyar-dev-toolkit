# آلت تصویر مهیار (Smart Alt Setter)

افزودن گروهی ALT فقط به تصاویری که واقعاً در نوشته‌ها و برگه‌های منتشرشده استفاده شده‌اند؛ فایل‌های بلااستفاده‌ی کتابخانه نادیده گرفته می‌شوند.

> **سطح ریسک:** 🟡 متوسط — متادیتا را گروهی می‌نویسد؛ متن‌ها **به ترتیب** اعمال می‌شوند

## چه کار می‌کند؟

- نوشته‌ها و برگه‌های منتشرشده را برای تصاویر درج‌شده با کلاس استاندارد `wp-image-ID` اسکن می‌کند
- متن ALT را از یک کادر متنی (هر خط یک ALT) یا **ستون اول CSV** می‌گیرد
- به ترتیب فقط به تصاویر استفاده‌شده‌ی **بدون ALT** می‌دهد — ALT موجود هرگز بازنویسی نمی‌شود
- تعداد تصاویر استفاده‌شده‌ی بدون ALT را نشان می‌دهد تا بدانی چند خط آماده کنی

> ⚠️ **مهم:** افزونه محتوای تصویر را نمی‌بیند. خط ۱ به اولین تصویر پیداشده می‌رسد، خط ۲ به دومی و همین‌طور ادامه. لیستت را به همان ترتیب آماده کن، اول روی کپی تست اجرا کن و چند نمونه را بررسی کن.
> تصاویر صفحه‌سازها یا تصویر شاخص که کلاس `wp-image-ID` در محتوا ندارند شناسایی نمی‌شوند.

## نصب و استفاده

۱. آپلود و فعال‌سازی. **آلت تصویر مهیار** را از منوی کناری باز کن (دسترسی مدیر لازم است).
۲. شمارنده‌ی «تصاویر بدون ALT» را ببین.
۳. متن‌های ALT را بچسبان (هر خط یک مورد) **یا** CSV آپلود کن.
۴. **افزودن ALTها** را بزن، سپس چند تصویر را در کتابخانه/سایت بررسی کن.

## تغییرات نسخه‌ی ۱٫۱٫۰

محافظت nonce/CSRF، بررسی دسترسی، پاک‌سازی ورودی و escape خروجی؛ حذف آیکون لینک‌شده از سایت خارجی؛ رد کردن خطوط خالی؛ افزودن شمارنده‌ی زنده.

## ⚠️ سلب مسئولیت

این افزونه **«همان‌طور که هست» (as is)** و بدون هیچ‌گونه ضمانتی ارائه می‌شود. **مسئولیت کامل نحوه‌ی استفاده با خود شماست**؛
از جمله رعایت قوانین کشور خودتان، شرایط استفاده‌ی هر سرویس/پلتفرم ثالث و قوانین حریم خصوصی و ضد اسپم.
سازنده (مهیار مومنی) و مشارکت‌کنندگان **هیچ مسئولیتی** در قبال خسارت، از دست رفتن داده، مسدود شدن حساب، جریمه‌ی موتور جستجو،
شکایت یا جریمه‌ی قانونی ناشی از استفاده یا سوءاستفاده ندارند.
فقط روی سیستم‌ها، سایت‌ها و داده‌هایی استفاده کن که مالک آن‌ها هستی یا اجازه‌ی کتبی داری.
