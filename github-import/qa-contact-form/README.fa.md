## امکانات

- **فرم‌ساز درگ‌اند‌دراپ** — متن، ایمیل، تلفن، متن چندخطی، انتخابی، چک‌باکس، رادیو، آپلود فایل، تاریخ
- **اعتبارسنج‌های ایرانی** — موبایل، کد ملی، کد پستی
- **آپلود فایل** — حداکثر حجم و نوع‌های مجاز قابل تنظیم
- **پاسخ خودکار** — ایمیل تأیید قابل شخصی‌سازی برای فرستنده
- **اعلان تلگرام** و **وب‌هوک** (Zapier / n8n / Make …) برای هر ارسال
- **ضداسپم چندلایه** — honeypot، محدودیت نرخ، reCAPTCHA اختیاری
- **خروجی CSV** پیام‌ها · **ویرایشگر زنده‌ی طراحی** (رنگ، فونت، چیدمان)

## پیش‌نیازها

وردپرس ۵.۸+ · PHP 7.4+ · ارسال ایمیل فعال (برای تحویل مطمئن افزونه‌ی SMTP توصیه می‌شود)

## نصب و استفاده

۱. آپلود و فعال‌سازی.
۲. **QA Contact Form** را از منوی کناری باز کن.
۳. فرم را بساز (فیلدها را بکش، برچسب/اعتبارسنجی بده)، طراحی را تنظیم کن و در صورت نیاز پاسخ خودکار / تلگرام / وب‌هوک را بگذار.
۴. **شورتکد** ساخته‌شده را در هر برگه یا نوشته‌ای بچسبان.
۵. یک پیام آزمایشی بفرست؛ فهرست پیام‌ها و صندوق ایمیلت را ببین.
۶. هر زمان لازم شد از پنل، خروجی CSV بگیر.

## حریم خصوصی و داده

پیام‌ها (و فایل‌های آپلودی) روی سرور خودت ذخیره می‌شوند. اعلان تلگرام و وب‌هوک داده‌ی ارسالی را به سرویس‌هایی که تنظیم کرده‌ای می‌فرستند؛ reCAPTCHA (در صورت فعال بودن) با گوگل ارتباط دارد.
اگر از بازدیدکنندگان داده‌ی شخصی می‌گیری، متن حریم خصوصی/رضایت بگذار و نگهداری را طبق قانون محلی (مثل GDPR) مدیریت کن.

## رفع مشکل

| مشکل | راه‌حل |
|---|---|
| ایمیل نمی‌رسد | SMTP تنظیم کن؛ پوشه‌ی اسپم و آدرس فرستنده را ببین |
| تلگرام کار نمی‌کند | توکن ربات و Chat ID را بررسی کن؛ ربات باید در چت/کانال مجاز باشد |
| آپلود رد می‌شود | نوع‌های مجاز و `upload_max_filesize` / `post_max_size` در PHP را ببین |
