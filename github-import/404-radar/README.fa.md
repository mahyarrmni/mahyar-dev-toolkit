# 404 Radar (رادار ۴۰۴)

خطاهای ۴۰۴ را می‌گیرد، نزدیک‌ترین صفحه را پیشنهاد می‌دهد و با ریدایرکت ۳۰۱ یک‌کلیکی اصلاحشان می‌کند. مینیمال، سریع، دوزبانه (فارسی/انگلیسی).

> **سطح ریسک:** 🟢 کم — درخواست‌های ۴۰۴ را ثبت می‌کند؛ ریدایرکت‌ها را خودت می‌سازی (ریدایرکت خودکار اختیاری است)

## امکانات

- آدرس‌های ۴۰۴ را با تعداد بازدید و **آدرس ارجاع‌دهنده (referrer)** ثبت می‌کند (افزونه آدرس IP ذخیره نمی‌کند)
- برای هر ۴۰۴ **نزدیک‌ترین صفحه‌ی موجود** را پیشنهاد می‌دهد (تطبیق شباهت نامک)
- **ریدایرکت ۳۰۱ یک‌کلیکی**؛ **ریدایرکت خودکار** اختیاری به بهترین گزینه و **فهرست قانون‌های regex** برای الگوهای URL
- به‌صورت اختیاری **ترافیک ربات‌ها** (پیش‌فرض روشن) و درخواست فایل‌های ایستا را ثبت نمی‌کند؛ لاگ را به تعداد روز قابل تنظیم (پیش‌فرض ۳۰) نگه می‌دارد
- **ایمیل خلاصه‌ی هفتگی** اختیاری برای مدیر؛ شمارنده‌ی روند ۱۴ روزه
- پنل تمیز فارسی و انگلیسی

## پیش‌نیازها

وردپرس ۵.۹+ (از `str_starts_with` استفاده می‌کند که از ۵.۹ پولی‌فیل شده) · PHP 7.4+

## نصب و استفاده

۱. آپلود و فعال‌سازی. **404 Radar** را از منوی کناری باز کن.
۲. چند روز بگذار داده جمع شود (یا برای تست یک آدرس ناموجود را باز کن).
۳. یک مورد را باز کن ← صفحه‌ی پیشنهادی را ببین ← اگر تطابق خوب است **Redirect** (۳۰۱) بزن.
۴. برای محتوای حذف‌شده‌ای که جایگزین مناسب ندارد، ۴۰۴ (یا ۴۱۰) را بگذار و ریدایرکت نکن.
۵. با *wipe* موارد بدون مقصد را پاک کن و نگهداری/ایمیل را در تنظیمات تنظیم کن.

## نکات سئو

ریدایرکت تعداد زیادی URL نامرتبط به صفحه‌ی اصلی یا صفحه‌ی کم‌ارتباط را موتورهای جستجو *soft 404* حساب می‌کنند. ریدایرکت خودکار **به‌صورت پیش‌فرض خاموش** است؛ تا اثرش را نفهمیدی خاموش نگهش دار.

## حریم خصوصی

داده‌ی ثبت‌شده: آدرس درخواستی، آدرس ارجاع‌دهنده (ممکن است query string داشته باشد)، زمان و تعداد بازدید. در صورت لزوم در سیاست حریم خصوصی ذکر کن. جدول لاگ و تنظیمات هنگام **حذف** افزونه (`uninstall.php`) پاک می‌شوند، نه با غیرفعال‌سازی.

## رفع مشکل

| مشکل | راه‌حل |
|---|---|
| چیزی ثبت نمی‌شود | ثبت در تنظیمات خاموش است، یا کش/CDN صفحه‌ی ۴۰۴ را قبل از وردپرس سرو می‌کند |
| ریدایرکت کار نمی‌کند | افزونه/قانون سرور دیگری اولویت دارد؛ کش را پاک کن |
