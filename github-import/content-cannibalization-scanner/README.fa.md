# Content Cannibalization Scanner (اسکنر کانیبالیزیشن محتوا)

افزونه‌ی وردپرس. کانیبالیزیشن کلمه‌ی کلیدی و قصد جستجوی تکراری را در نوشته‌هایت پیدا می‌کند و (v2.2) امنیت سایت را هم ممیزی می‌کند.

> **سطح ریسک:** 🟡 متوسط — به‌صورت پیش‌فرض فقط‌خواندنی است، ولی اقدام‌های اصلاح خودکار اختیاری محتوا/فایل را تغییر می‌دهند (بکاپ و بازگردانی دارد)

## چه کار می‌کند؟

**ماژول سئو**
- نوشته‌های منتشرشده را برای هم‌پوشانی کلمه‌ی هدف و قصد جستجوی تکراری اسکن می‌کند
- تگ canonical و اقدام ادغام پیشنهاد می‌دهد؛ صفحات کم‌محتوایی که اعتبار رتبه را تقسیم می‌کنند را علامت می‌زند
- مقایسه‌ی اختیاری Cloaking / ریدایرکت شرطی (آنچه Googlebot، بازدیدکننده‌ی عادی و بازدیدکننده‌ی آمده از گوگل دریافت می‌کنند)

**گزارش سایت / ماژول امنیت (v2.2)**
- اسکن امضای بدافزار با فید امضاشده‌ی Ed25519 که از راه دور به‌روز می‌شود
- بررسی آسیب‌پذیری افزونه/قالب/هسته با WPVulnerability.net (بدون کلید) یا Wordfence Intelligence
- بررسی Google Safe Browsing (نیاز به کلید API) · بررسی سلامت فایل‌های هسته‌ی وردپرس
- **پیش‌نمایش (Dry-run)** قبل از هر اصلاح؛ هر اصلاح یک بکاپ ZIP فشرده می‌سازد و با یک کلیک قابل بازگردانی است

> **نکته‌ی بسته:** ماژول امنیت کلاس‌هایش را از مجموعه‌ی `includes/class-cs-audit*.php` و ابزار فید را از `tools/` بارگذاری می‌کند.
> اگر این پوشه‌ها در نسخه‌ی نصب‌شده نباشند، اسکنر سئو کار می‌کند ولی *گزارش سایت* غیرفعال می‌شود. از نسخه‌ی کامل استفاده کن.

## پیش‌نیازها

وردپرس ۵.۸+ · PHP 7.4+

## نصب و استفاده

۱. در `/wp-content/plugins/` آپلود و فعال کن.
۲. **Cannibalization Scanner** را از منوی کناری باز کن.
۳. **اسکن سئو** را اجرا کن ← هر گروه تداخل را باز کن ← تصمیم بگیر: ادغام، متمایزسازی یا تعیین canonical.
۴. برای امنیت، **Site Report** را باز کن ← اسکن ← یافته‌ها را ببین ← اول **dry-run** ← فقط بعد از خواندن پیش‌نمایش اصلاح را اعمال کن.

## حریم خصوصی و مسیر داده

جستجوی آسیب‌پذیری نام و نسخه‌ی افزونه/قالب را به WPVulnerability.net / Wordfence Intelligence می‌فرستد؛ Safe Browsing آدرس سایتت را به گوگل می‌فرستد؛ فید بدافزار از آدرس فید تنظیم‌شده در افزونه دانلود می‌شود. محتوای نوشته‌ها روی سرورت می‌ماند.

## رفع مشکل

| مشکل | راه‌حل |
|---|---|
| تب Site Report نیست/خالی است | فایل‌های `includes/` نصب نیستند — از نسخه‌ی کامل نصب کن |
| اسکن تایم‌اوت می‌شود | روی نوشته‌های کمتر اجرا کن یا `max_execution_time` را بالا ببر |
| فید راه دور خطا می‌دهد | دسترسی HTTPS خروجی سرور را بررسی کن |

## ⚠️ نکته

اصلاح خودکار فایل‌های سایت را تغییر می‌دهد. همیشه بکاپ خودت را داشته باش، اول روی staging تست کن و خروجی اسکنر را سرنخ بررسی دستی بدان، نه دلیل قطعی آلودگی یا سلامت.
