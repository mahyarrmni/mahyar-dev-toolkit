> **سطح ریسک:** 🔴 زیاد — کامنت مصنوعی می‌تواند فریبنده باشد و با سیاست‌های اسپم و قوانین حمایت از مصرف‌کننده در تعارض قرار گیرد

## چه کار می‌کند؟

- محتوای نوشته را می‌خواند و با **Gemini** کامنت مرتبط تولید می‌کند (مدل در تنظیمات قابل تغییر؛ زبان پیش‌فرض فارسی)
- **صف جاب انبوه** مبتنی بر WP-Cron: برای نوشته‌های انتخابی جاب بساز و در لاگ و آمار دنبال کن
- **زمان‌بندی هوشمند:** فاصله‌ی تصادفی بین کامنت‌ها، بازه‌ی ساعت مجاز و (اختیاری) تاریخ‌گذاری عقب‌تر (پیش‌فرض ۱ تا ۶۰ روز)
- **انواع کامنت** (قابل روشن/خاموش): تعریف · پرسش · نقد · تجربه · پیشنهاد · مخالفت · ادامه‌ی گفتگو، به‌علاوه‌ی درصد قابل تنظیم پاسخ
- کنترل لحن هر نوشته، محدودیت طول، بودجه‌ی روزانه، رد کردن نوشته‌های دارای کامنت
- لاگ دیباگ با چرخش (حداکثر ۵ مگابایت)

## پیش‌فرض ایمن‌تر (از این نسخه)

کامنت‌های جدید به‌صورت **در انتظار تأیید** ساخته می‌شوند (`auto_approve` به‌صورت پیش‌فرض **خاموش** است). فقط اگر ریسک زیر را می‌فهمی آن را روشن کن.

## پیش‌نیازها

وردپرس ۵.۵+ · PHP 7.4+ · کلید API جمینای · WP-Cron فعال

## نصب و استفاده

۱. آپلود و فعال‌سازی؛ **💬 Seeder** را از منوی کناری باز کن (زیرمنوها: داشبورد · ایجاد جاب · تنظیمات · لاگ جاب‌ها · آمار).
۲. **تنظیمات:** کلید Gemini، زبان، محدودیت‌ها، بازه‌ی ساعت و تأیید دستی کامنت را تنظیم کن (تأیید دستی را **روشن** نگه دار).
۳. **ایجاد جاب:** نوشته‌ها را انتخاب کن، لحن/تعداد را بده و جاب را در صف بگذار.
۴. در **لاگ جاب‌ها** و **آمار** پیشرفت را ببین؛ کامنت‌های در انتظار را قبل از تأیید در بخش *دیدگاه‌ها ← در انتظار* بازبینی کن.

## ⚠️ هشدار ریسک (حتماً بخوان)

این افزونه کامنت‌هایی تولید می‌کند که شبیه نوشته‌ی بازدیدکننده‌اند، حتی با تاریخ عقب‌تر و محتوای «تجربه» یا «نقد» متنوع. ارائه‌ی متن ماشینی به‌عنوان نظر واقعی خوانندگان **بازدیدکننده را گمراه می‌کند** و
نظر/بازخورد جعلی در بسیاری از کشورها ممنوع یا تحت نظارت است (قوانین حمایت از مصرف‌کننده و تبلیغات؛ مثل مقررات FTC آمریکا، قواعد رویه‌های تجاری ناعادلانه‌ی اتحادیه‌ی اروپا و معادل‌های محلی).
موتورهای جستجو محتوای خودکار/جعلی کاربران را اسپم می‌دانند و می‌تواند به اعتبار و رتبه‌ی سایتت آسیب بزند.

کاربردهای مشروع‌تر و کم‌ریسک: **سایت‌های تست/دمو**، تست رابط کاربری، یا پیش‌نویس پاسخ‌هایی که انسان ویرایش و با هویت واقعی و آشکار منتشر می‌کند. از آن برای ساخت اعتبار اجتماعی، نظر یا تعامل جعلی روی سایت زنده‌ی عمومی
و گذاشتن کامنت مصنوعی در سایت‌هایی که مالکشان نیستی استفاده نکن. **همه‌ی پیامدهای استفاده کاملاً بر عهده‌ی خود کاربر است.**

## حریم خصوصی و مسیر داده

محتوا/خلاصه‌ی نوشته برای تولید متن به API جمینای گوگل ارسال می‌شود. کلید API در جدول options وردپرس ذخیره می‌شود.

## رفع مشکل

| مشکل | راه‌حل |
|---|---|
| جاب‌ها در صف می‌مانند | WP-Cron اجرا نمی‌شود — کرون واقعی سرور برای `wp-cron.php` بگذار |
| خطای API | کلید، نام مدل و سهمیه را در Google AI Studio بررسی کن |
| جاب گیر کرده | بعد از timeout (پیش‌فرض ۶۰۰ ثانیه) خودکار ریست می‌شود |
