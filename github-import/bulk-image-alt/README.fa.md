# آلت گروهی تصویر (Bulk Image Alt)

تنظیم گروهی ALT برای تصاویر کتابخانه‌ی رسانه که ALT ندارند، با گزارش ممیزی و عملیات «حذف همه‌ی ALTها» با محافظت.

## چه کار می‌کند؟

- متن ALT (کادر متنی، هر خط یکی، یا ستون اول CSV) را به **همه‌ی تصاویر کتابخانه که ALT ندارند** به ترتیب می‌دهد
- **گزارش:** کل تصاویر، دارای ALT، بدون ALT و فهرست تصاویر بدون ALT (با لینک فایل)
- **حذف همه‌ی ALTها** — غیرقابل بازگشت؛ تیک تأیید و nonce لازم دارد

> ⚠️ ALTها **به ترتیب** اعمال می‌شوند، نه بر اساس محتوای تصویر؛ افزونه نمی‌تواند متن را با تصویر تطبیق دهد. وقتی لیست مرتب آماده داری استفاده کن، یا به‌عنوان پیش‌نویس اولیه که بعداً اصلاحش می‌کنی.
> روی کل کتابخانه کار می‌کند (نه فقط تصاویر استفاده‌شده در نوشته‌ها) — اگر فقط تصاویر استفاده‌شده را می‌خواهی از *Smart Alt Setter* استفاده کن.

## نصب و استفاده

۱. آپلود و فعال‌سازی. **آلت گروهی تصویر** را از منوی کناری باز کن.
۲. اعداد گزارش را ببین.
۳. متن‌ها را بچسبان یا CSV آپلود کن ← **افزودن ALTها**.
۴. گزارش را دوباره باز کن و کاهش «بدون ALT» را ببین.
۵. (اختیاری، مخرب) برای پاک کردن همه‌ی ALTها تیک تأیید را بزن و **حذف تمام ALTها** را بزن — اول بکاپ بگیر.

## تغییرات نسخه‌ی ۱٫۳٫۰

محافظت nonce/CSRF روی هر دو عملیات، بررسی دسترسی، ورودی پاک‌سازی‌شده، خروجی escape‌شده؛ توضیح افزونه با رفتار واقعی هماهنگ شد.

## ⚠️ سلب مسئولیت

از جمله رعایت قوانین کشور خودتان، شرایط استفاده‌ی هر سرویس/پلتفرم ثالث و قوانین حریم خصوصی و ضد اسپم.
