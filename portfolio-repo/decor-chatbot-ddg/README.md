## 🇮🇷 درباره این ابزار

یک چت‌بات دسکتاپ فارسی‌زبان ساخته‌شده با Flet که سوالات دکوراسیون داخلی را تشخیص می‌دهد و با جستجوی زنده در DuckDuckGo پاسخ می‌دهد. بدون نیاز به API پولی — کاملاً رایگان.

### ✨ قابلیت‌ها

- 🗣️ **گفتگوی فارسی** — رابط کاملاً RTL و فارسی
- 🔍 **تشخیص موضوع** — فقط به سوالات دکوراسیون پاسخ می‌دهد
- 🌐 **جستجوی زنده** — نتایج به‌روز از DuckDuckGo
- 🧵 **پردازش غیرهمزمان** — UI هنگام جستجو قفل نمی‌شود
- 💬 **تاریخچه چت** — نمایش کامل مکالمه

### 🎯 کلمات کلیدی تشخیص‌داده‌شده

دکوراسیون، چیدمان، مبلمان، رنگ، نورپردازی، طراحی داخلی، سبک مدرن، مینیمال، کلاسیک، بوهمی، فرش، کابینت، پرده و ۳۵+ کلمه دیگر.

## 🇬🇧 About

A Persian-language Flet desktop chatbot specialized in interior design questions. Uses DuckDuckGo search API for real-time results — no paid API required. Includes keyword-based topic detection to only answer interior design questions.

**Keywords:** python interior design chatbot, flet chatbot persian, duckduckgo search python, free AI chatbot python, home decor assistant python, RTL flet app, persian chatbot flet
