## 🇮🇷 درباره این ابزار

یک ابزار وب کامل برای بهینه‌سازی و تبدیل تصاویر با رابط کاربری Streamlit. فایل‌های تصویری را آپلود کنید، فرمت خروجی و کیفیت را تنظیم کنید، واترمارک اضافه کنید و همه را یک‌جا دانلود کنید.

### ✨ قابلیت‌ها

- 🔄 **تبدیل فرمت** — WEBP، AVIF، JPEG، PNG
- 📦 **پردازش دسته‌ای** — چند فایل همزمان
- 💧 **واترمارک متنی** — موقعیت، رنگ و شفافیت قابل تنظیم
- 🔗 **دانلود از URL** — اسکرپ و دانلود تصاویر از وب
- 📥 **خروجی ZIP** — دانلود همه تصاویر در یک فایل
- 🎛️ **تنظیم کیفیت** — ۱ تا ۱۰۰ برای JPEG/WEBP

---

## 🇬🇧 About

A full-featured Streamlit web app for image optimization and format conversion. Upload images, choose output format (WEBP/AVIF/JPEG/PNG), set quality, add text watermarks, and download all as a ZIP. Supports URL scraping for bulk downloads.

**Keywords:** python image optimizer, webp converter python, avif converter, streamlit image tool, bulk image converter, pillow image processing, image watermark python, batch image resize python

## 🚀 نصب و اجرا / Installation

```bash
pip install streamlit pillow requests beautifulsoup4

streamlit run Imageoptimizer.py
```

| کتابخانه | کاربرد |

| `zipfile` | ساخت آرشیو ZIP |
